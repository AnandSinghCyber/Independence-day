# Anand Mobile & Electrics — Independence Day Website

A responsive one-page Independence Day greeting microsite for Anand Mobile & Electrics, Sachin, Surat.

## Files
- `index.html` — page structure/content
- `style.css` — responsive design and animations
- `script.js` — lightweight decorative animation

## Run
Open `index.html` directly in a browser. No server or build step is required.

## Customise
Replace the brand mark with your real `logo.png` if desired, and add your phone/WhatsApp link, exact shop address, Google Maps link, or social links to the CTA/contact area.
